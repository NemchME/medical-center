## Краткое описание

**Medecina** — full-stack TypeScript приложение для амбулаторных медицинских центров. Объединяет:

- **Frontend** на React + Vite (публичный сайт + личные кабинеты пациента/врача/администратора)
- **Backend** на NestJS + Prisma + PostgreSQL
- **ML-модуль** — модель прогноза неявки пациента (`GradientBoostingClassifier`, ONNX, inference в Node.js)

### Ключевые возможности

- Запись пациентов на приём с автоматическим расчётом риска неявки
- Личный кабинет врача: расписание, история пациентов, ведение визитов
- Админка: управление врачами, пациентами, центрами, услугами, аналитика
- Уведомления (24ч / 1ч до приёма)
- Открытый каталог: врачи, услуги, анализы, центры
